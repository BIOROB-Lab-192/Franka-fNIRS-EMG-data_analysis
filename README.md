## Data Pipeline

The analysis runs through three marimo notebooks, each handling one sensor modality:

### 1. EMG Processing (`notebooks/emg_csv.py`)

Processes Trigno EMG/IMU sensor data through the full pipeline:

```
load_trigno_csv → sync_sensor_streams → handle_dropouts →
generate_epochs → add_metadata → merge_metadata → filter_epoch_window
```

- **Sync**: All sensor channels aligned to the fastest sensor (~1926 Hz) via `join_asof nearest`
- **Dropouts**: EMG zeros → null (honest), IMU zeros → interpolated (physically smooth)
- **Epochs**: 30 epochs per session, 15s task windows, 40s intervals
- **Output**: `data/processed/all_emg_epochs.parquet` (8.7M rows × 28 cols)

### 2. Robot Processing (`notebooks/robot_csv.py`)

Processes Franka robot telemetry CSVs:

```
load_data → process_robot_file → build_giant_robot_csv →
filter to first 15s → export
```

- **Task splitting**: Handles repeated markers by splitting runs into separate task instances
- **Fixed schema**: Consistent columns across all sessions (Franka_ee/q/dq/tau_J as string arrays)
- **Output**: `data/processed/robot_first_15s.csv`

### 3. fNIRS Analysis (`notebooks/fnirs_analysis.py`)

Group-level fNIRS analysis using MNE:

```
read_raw_snirf → resample(10 Hz) → concatenate →
optical_density → scalp_coupling_index → beer_lambert_law →
bandpass_filter → epoch → compare robot vs norobot
```

- **Resampling**: All SNiRF files resampled to 10 Hz before concatenation (fixes floating-point sfreq drift)
- **Bad channel detection**: Scalp coupling index < 0.3
- **Output**: `data/processed/combined_fnirs.csv`

## Data Combiner (`src/sync/data_combiner.py`)

Combines all three streams into a single resampled file and a full-resolution data packet.

### Usage

```bash
# Build combined dataset
python -m src.sync.data_combiner

# Verify existing build
python -m src.sync.data_combiner --verify-only

# Custom paths
python -m src.sync.data_combiner --emg PATH --robot PATH --fnirs PATH --output DIR
```

### What It Does

1. **Loads** EMG (parquet), Robot (CSV), fNIRS (CSV) with normalized time columns
2. **Verifies** epoch alignment across all three streams (per-run breakdown table)
3. **Resamples** each stream to 100 Hz on a −5 to 15s time grid (2001 points/epoch)
4. **Combines** into a single parquet file (fNIRS as base, EMG/Robot left-joined)
5. **Exports** full-resolution data packet alongside the combined file
6. **Verifies** the output (null patterns, file sizes, sample epoch check)

### Output

```
data/processed/combined/
├── combined_100hz.parquet      # All streams at 100 Hz (125 MB)
└── data_packet/                # Full resolution
    ├── emg_full.parquet        # ~1926 Hz
    ├── robot_full.parquet      # Variable rate
    ├── fnirs_full.parquet      # ~10 Hz
    └── epoch_index.csv         # Metadata per epoch
```

See [`data/processed/combined/README.md`](data/processed/combined/README.md) for detailed documentation of the combined file.

## Data Format

### Raw Data Structure

```
data/raw/{participant}_{condition}{num}/
├── {session_date}/
│   └── {session_date}.snirf        # fNIRS (SNiRF format)
├── {EMG_filename}.csv              # Trigno EMG/IMU
└── WMFT_{task}/
    └── part{N}.csv + .mp4          # Robot + video
```

Folder naming: `^{participant}_{robot|norobot}{num}$`
- Examples: `JohnDoe_robot1`, `JaneDoe_norobot`, `DoeJane_robot4`

### Trigno CSV Format

Complex multi-rate CSV with:
- Sensor names in a row above the main header
- Multiple channels at different sampling rates (EMG ~1926 Hz, ACC/GYRO ~148 Hz)
- Column naming: `{Sensor Name} | {Channel} ({unit})`
- Separate marker table at the end

Handled by `load_trigno_csv()` in the EMG notebook.

### Sessions

Each session folder follows the naming pattern `{participant}_{robot|norobot}{num}`:

```
data/raw/
├── JohnDoe_robot1/          # JohnDoe, robot-assisted
├── JohnDoe_norobot1/        # JohnDoe, no robot
├── JaneDoe_robot1/     # JaneDoe, robot-assisted
├── JaneDoe_norobot1/   # JaneDoe, no robot
└── ...
```

The dataset contains complete experiment sessions across multiple participants, each with robot-assisted and non-robot-assisted conditions.

## Exported Parquet Schema (EMG)

The `all_emg_epochs.parquet` file contains:

| Column | Description |
|--------|-------------|
| `time` | Time relative to recording start (seconds) |
| `task_instance` | Epoch number (1–30) |
| `run_id` | Session identifier |
| `is_robot` | Robot condition (boolean) |
| `participant` | Participant name |
| `epoch_start` | Marker time for this epoch |
| `{Sensor} \| {Channel}` | Sensor data columns (EMG mV, ACC G, GYRO deg/s) |
